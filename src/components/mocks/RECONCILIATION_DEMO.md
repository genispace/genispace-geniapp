# 财务智能对账系统演示说明

## 概述

这是一个基于 GeniSpace 平台的财务智能对账系统演示工作台。演示展示了如何利用平台的数据源管理、工作流引擎和工作台功能，构建一个完整的财务对账解决方案。

## 访问方式

```
http://localhost:5013/workbench/demo-reconciliation/dashboard
```

## 功能说明

### 页面1：对账管理首页（dashboard）

**功能特性**：
- **统计卡片组**：展示总对账任务数、本月完成数、平均匹配率、待处理差异数
- **最近对账任务列表**：显示最近的对账任务，包括任务名称、基准表、对账日期、状态、匹配率
- **匹配率趋势图**：展示最近30天的匹配率变化趋势

**使用场景**：
- 快速了解对账工作整体情况
- 查看最近的对账任务状态
- 分析匹配率趋势，评估对账质量

### 页面2：基准表管理（baseline-tables）

**功能特性**：
- **基准表列表**：显示所有基准表（银行日记账或银行流水）
- **表信息**：表名、类型、记录数、最后更新时间、状态
- **操作功能**：查看、编辑、删除、设为默认

**使用场景**：
- 管理用于对账的基准表
- 查看基准表的基本信息和状态
- 设置默认基准表，简化对账任务创建流程

**业务价值**：
- **标准化管理**：统一管理所有基准表，确保数据一致性
- **快速选择**：通过基准表列表快速选择对账基准
- **数据追溯**：记录基准表的创建和更新时间，便于审计

### 页面3：创建对账任务（create-task）

**功能特性**：
- **工作流组件**：使用 WorkflowComponent 实现多步骤对账流程
- **步骤1：选择基准表**
  - 从数据源列表选择基准表
  - 预览基准表数据（前10条记录）
- **步骤2：上传对账文件**
  - 支持 Excel (.xls, .xlsx) 和 PDF 格式
  - 文件预览和验证
- **步骤3：字段映射配置**
  - 配置对账文件的字段映射关系
  - 选择交易日期、金额、对方户名、摘要等字段
- **步骤4：配置匹配规则**
  - 设置金额容差（默认0.01元）
  - 设置日期容差（默认3天）
  - 设置最低匹配得分（默认70分）
- **步骤5：执行对账**
  - 显示对账进度
  - 实时日志输出
  - 自动跳转到结果页面
- **步骤6：查看结果**
  - 匹配统计信息
  - 差异列表
  - 未匹配记录

**使用场景**：
- 创建新的对账任务
- 配置对账参数和规则
- 执行对账并查看结果

**业务价值**：
- **流程化操作**：通过步骤化流程，确保对账任务创建的完整性和准确性
- **灵活配置**：支持自定义字段映射和匹配规则，适应不同数据格式
- **实时反馈**：执行过程中实时显示进度和日志，提升用户体验

### 页面4：对账结果详情（reconciliation-result）

**功能特性**：
- **结果概览卡片**：总记录数、匹配数、未匹配数、差异数
- **匹配结果表格**：
  - 显示所有匹配的记录
  - 基准记录和对账记录的对比
  - 匹配得分和匹配类型（精确匹配/模糊匹配）
- **差异分析表格**：
  - 差异类型（金额差异、日期差异、未匹配）
  - 差异金额和差异天数
  - 严重程度（严重、警告、正常）
- **未匹配记录表格**（Tabs）：
  - Tab1：未匹配的基准记录
  - Tab2：未匹配的对账记录
- **匹配率趋势图**：按日期展示匹配率变化

**使用场景**：
- 查看详细的对账结果
- 分析差异原因
- 处理未匹配记录
- 评估对账质量

**业务价值**：
- **全面分析**：提供多维度对账结果分析，帮助财务人员快速定位问题
- **差异识别**：自动识别金额差异、日期差异等，减少人工检查工作量
- **可视化展示**：通过图表和表格直观展示对账结果，提升分析效率

## 业务流程

### 标准对账流程

1. **建立基准表**
   - 在数据源管理中创建数据源
   - 通过 SQL 查询或文件上传建立基准数据
   - 基准表可以是银行日记账或银行流水

2. **创建对账任务**
   - 选择基准表（数据源）
   - 上传对账文件（Excel/PDF）
   - 配置字段映射关系
   - 设置匹配规则（金额容差、日期容差等）

3. **执行对账**
   - 通过工作流执行对账匹配
   - 实时查看对账进度
   - 自动识别差异和异常

4. **查看结果**
   - 在工作台查看对账结果
   - 分析匹配率和差异
   - 处理未匹配记录
   - 导出对账报告

## 技术实现

### 组件架构

演示使用工作台的标准组件：

- **StatisticGroup**：统计卡片组，展示关键指标
- **Table**：数据表格，展示列表数据
- **Chart**：图表组件，展示趋势数据
- **WorkflowComponent**：工作流组件，实现多步骤流程
- **Tabs**：标签页组件，组织多个表格

### 数据源集成

- **基准表管理**：通过数据源（Datasource）功能管理基准表
- **数据查询**：通过数据源 SQL 查询接口访问基准数据
- **结果存储**：对账结果存储在数据库中，可通过数据源查询

### 工作流集成

- **工作流构建**：在 TaskStudio 中构建对账工作流
- **节点类型**：数据源节点、操作符节点、控制节点
- **执行监控**：实时查看工作流执行进度和日志

## 注意事项

1. **数据安全**：财务数据敏感，需要严格的权限控制和数据加密
2. **数据格式**：确保上传的文件格式正确，字段映射准确
3. **匹配规则**：根据实际业务需求调整匹配规则，平衡准确性和效率
4. **差异处理**：及时处理差异和未匹配记录，确保对账完整性
5. **审计要求**：保留完整的对账记录和操作日志，便于审计
